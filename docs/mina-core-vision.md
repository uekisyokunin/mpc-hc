# MinaCore Player 構想メモ

\# MinaCore Player 構想メモ



\## 1. 目標

⦁　MPC-HC をベースにした「多画面・区間リピート特化、語学学習、映像鑑賞愛好家、映像作家向けの多機能動画プレーヤーの開発」



\## 2. コア機能（MVP）

* マルチプレーヤー: 複数動画の同時再生・管理
* 相対パス管理: ローカルファイルの自動読み込み
* 完全自動ファイル検索: File System Access API活用による高度な検索
* A-Bループ: 区間リピート機能
* プロジェクト管理: 作業状態の保存・読み込み
* デバッグ機能: 包括的なシステム情報表示



\## 3. 将来追加したい機能

* &nbsp;ショートカット強化、UI スキン変更、波形表示 etc.



\## 4. 優先度

⦁　最優先で実装したいもの(A-Bループ: 区間リピート機能、プロジェクト管理: 作業状態の保存・読み込み、マルチプレーヤー: 複数動画の同時再生・管理、相対パス管理: ローカルファイルの自動読み込み、完全自動ファイル検索: File System Access API活用による高度な検索)

⦁　後回しでいいもの
デバッグ機能: 包括的なシステム情報表示
